ATM-C · Coordenadas

Una trayectoria. Dos traductores. Ninguna segunda fuente de verdad.

1 · Entrada externa → intención

Laboratorio real de IndexedDB, QIPU-META-1. Cada sesión crea una base nueva. Requiere localhost o HTTPS, sin CDN. No es un servicio público.

Iniciar para utilizar.

2 · Preguntar a la trayectoria
Selector de lectura: [], [t], [t,v] o [t,v,i].
3 · Derivado → JSON externo
Consultar no anexa acontecimientos. SET reemplaza una celda; ADD/SUB son diferenciales. DEF sigue siendo explícito en este perfil. El traductor no concede autoridad.
4 · Principio de primera aparición
El recorrido asigna posiciones por primera aparición reconocida. El contrato histórico QIPU-META-1 exige una declaración previa; T13 de Qipu 2.1.0 permite otros ámbitos de constitución. No se cambia el núcleo ni se confunden los perfiles. La API de frontera opera con coordenadas [t,v,i], y las primeras apariciones aún requieren nombres irreducibles.
