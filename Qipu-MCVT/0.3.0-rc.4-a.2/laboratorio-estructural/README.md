# Qipu A.2 · Laboratorio estructural
## Decisión de diseño
Priorizar escritura estructural por ruta global con un único escritor lógico. Conservar la causalidad explícita DEPEND/CAUSE como opción adicional para verdaderas consecuencias automáticas. No sustituir el código A.2 ni eliminar TX: admisión conjunta y recorrido estructural son preguntas distintas. No confundir los dos niveles de iteración (geometría/acontecimientos) con un resolvedor de dependencias causales.
## Qué se prueba
Cuatro escenarios que usan World.write, sin DEPEND/CAUSE: CRM (cliente/conversación/seguimiento), comercio (venta/entrega), proyecto (tabla de colaboradores y tarea histórica), documento (vector con trayectoria de revisiones y lista terminal). 18 intenciones directas; cada una añade un marco a raíz, conservando prefijos. Se comprueban manifestaciones, historias locales y replay; 43 comparaciones de historias por corte. Otro escenario atraviesa seis fronteras, con ADD terminal y APPEND en cada ancestro. Rechazo de ruta inválida, lista terminal no navegable, TX para stock/confirmación y reintento exacto. Comparación explícita frente a DEPEND/CAUSE: los mismos valores finales, dos nuevos registros exteriores en ambos casos, pero diferente constitución previa, responsabilidad y eventos interiores. La variante estructural necesita una segunda intención explícita; no realiza una reacción automática por sí sola.
## Uso del HTML
laboratorio.html incorpora exactamente K2P/K4B/K5B de RC.3 (fragmento anterior a Motor) y comun.js, sparse.js, trayectorias.js de A.2, más escenarios.js. No requiere CDN. Web Crypto en contexto seguro (localhost/HTTPS). Seleccionar escenario, ejecutar pasos, consultar cortes y rutas, ver frontera, historia, exportar bytes, ejecutar comparación y pruebas. Para probar localmente servir el directorio por HTTP localhost. El HTML es una ampliación del laboratorio anterior de RC.4; este permanece histórico e intacto. Atlas específico sobre naturaleza de celda, cuándo elegir trayectoria, composición de rutas, historia, cortes, lectura vs registro, comparación causal.
